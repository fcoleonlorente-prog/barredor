Primera publicación descargable de **Barredor para Windows x64**, preparada para Nexo Launcher.

- Instalador con asistente, icono propio y versión registrada en Windows.
- Inventario de programas, desinstalación y revisión de restos; incluye las herramientas presentes en el código de esta versión.
- Archivo `SHA256SUMS.txt` para comprobar la integridad de la descarga.

**Versión de prueba sin firma digital.** La compilación se publica después de instalarla y ejecutar su autoprueba en un entorno Windows de GitHub Actions. Esto no garantiza compatibilidad con todos los equipos ni sustituye una revisión completa de seguridad.

Antes de borrar archivos, claves o componentes, revisa la selección y conserva una copia independiente de tus datos. Las copias del registro no recuperan todos los archivos ni equivalen a una copia del equipo.

En Nexo Launcher 0.2.0, pulsa Actualizar para consultar la publicación. La descarga del instalador se verifica antes de pedir confirmación para ejecutarlo.
